# Final CSVs — Ndung'u Encumbrance Certificate system

The canonical data the certificate engine (`scripts/cert_engine.py`) consumes.
These are copies of the live files under `output/`; regenerate with
`stack_master.py` → `refine_master.py` (parcels) and `consolidate_aux.py`
(non-parcel findings), then re-copy here.

## Searchable set (loaded by the engine)

| File | Rows | Role |
|---|---|---|
| `parcel_index.csv` | 13,002 | Search index — one row per unique parcel key (LR/plot): n_findings, volumes, recommendations, record_ids. |
| `master_findings.csv` | 15,158 | Core parcel findings across Vols I–III (lean schema). |
| `aux_findings.csv` | 2,581 | Non-parcel encumbrance findings (schools, road reserves, companies, corporations, complaints, forest-excision schemes) in the same lean schema. Unkeyed → reached by name/descriptive search. |
| `forest_scheme_recommendations.csv` | 11 | Scheme-level recommendation fallback for Vol II forest excisions (keyed by station name). |
| `flagged_parcels_vol1.csv` | 5,469 | Vol I per-finding extras (reserved_use, current_use, allocating_authority) joined by record_id. Incl. Annex 24 Kenya Railways sales. |
| `flagged_parcels_vol2.csv` | 8,738 | Vol II extras (forest, allottee_id, registration_date, …). |
| `flagged_parcels_vol3.csv` | 371 | Vol III extras. |
| `flagged_parcels_vol3_forest.csv` | 37 | Vol III forest case-study named grabs. |
| `flagged_parcels_vol3_religious.csv` | 55 | Vol III religious-institution grabs. |

## Search reachability — EVERYTHING is searchable
All **17,739** findings (15,158 parcel + 2,581 non-parcel) are reachable; **0 stranded**.
Cascade: **parcel key (LR/plot) → ID number → allottee/entity name → descriptive
reference** (parcel_display / reserved_use / location, for records with no key/name/id).
